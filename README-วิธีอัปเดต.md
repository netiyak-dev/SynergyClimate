# คู่มือการอัปเดตเว็บ SynergyClimate (ฉบับใช้งานจริง)

หน้าเว็บนี้ออกแบบให้ **แก้เนื้อหาที่ไฟล์เดียว** คือ `assets/content.js`
ไม่ต้องรู้เรื่องเขียนโปรแกรมก็อัปเดตได้ ✅ และตอนนี้มี **เครื่องมือฟอร์ม** ให้ใช้แทนการพิมพ์โค้ดเองได้แล้ว

---

## 0. วิธีที่ง่ายที่สุด: ใช้เครื่องมือ `admin.html` (แนะนำ)

ไม่ต้องแตะโค้ดเลยแม้แต่บรรทัดเดียว — และตอนนี้กดปุ่มเดียวก็อัปเดตไฟล์จริงได้เลย ไม่ต้องดาวน์โหลด-วางทับเอง:

1. เปิดไฟล์ **`admin.html`** (อยู่โฟลเดอร์เดียวกับ `index.html`) ด้วย **Chrome หรือ Edge** — ดับเบิลคลิกได้เลย
   (ฟีเจอร์บันทึกไฟล์ตรงในข้อ 4 รองรับเฉพาะเบราว์เซอร์ตระกูล Chrome/Edge — ถ้าใช้ Safari หรือ Firefox จะยังใช้งานฟอร์มได้ปกติ แต่ต้องดาวน์โหลด/คัดลอกไปวางทับเอง ดูหมายเหตุด้านล่าง)
2. ระบบจะดึงข้อมูลปัจจุบันจาก `content.js` มาใส่ในฟอร์มให้อัตโนมัติ
3. เลือกแท็บด้านซ้าย (ข่าวสาร / ปฏิทิน / แกลเลอรี / งานของเรา / งานวิจัย / ทีมงาน / บริจาค ฯลฯ)
   แล้วแก้ในช่องกรอกได้เลย — มีปุ่ม **+ เพิ่ม**, **↑ ↓ เลื่อนลำดับ**, **✕ ลบ** ให้ในทุกรายการ
4. เสร็จแล้วกดปุ่ม **💾 อัปเดต content.js เลย** มุมขวาบน
   - ครั้งแรกที่กด เบราว์เซอร์จะเปิดหน้าต่างให้เลือกไฟล์ — เลือกไฟล์ **`assets/content.js`** ของโฟลเดอร์นี้ แล้วกดอนุญาตให้เขียนไฟล์
   - จากนั้นทุกครั้งที่แก้ฟอร์มแล้วกดปุ่มนี้ซ้ำ ระบบจะเขียนทับไฟล์ `content.js` ให้อัตโนมัติทันที ไม่ต้องเลือกไฟล์ใหม่ (ยกเว้นเบราว์เซอร์ขอสิทธิ์ยืนยันซ้ำเป็นบางครั้ง ก็แค่กดอนุญาตอีกที)
   - เสร็จแล้วเผยแพร่เว็บตามปกติ (ดูข้อ 7)

> 💡 ถ้าเบราว์เซอร์ไม่รองรับปุ่ม "อัปเดต content.js เลย" (เช่น Safari/Firefox) หรืออยากได้ไฟล์แยกไว้ดูก่อน ให้ใช้ปุ่ม **"⬇ ดาวน์โหลด content.js"** แทน จะได้ไฟล์ `content.js` ใหม่มาวางทับไฟล์ `assets/content.js` เดิมเอง หรือกด **"คัดลอกโค้ด"** แล้ววางทับเนื้อหาทั้งหมดในไฟล์ด้วยโปรแกรมแก้ไขข้อความ (เช่น TextEdit / VS Code) ก็ได้เช่นกัน
>
> ⚠️ `admin.html` เป็นเครื่องมือส่วนตัวของทีม ไม่ต้องผูกลิงก์จากเมนูเว็บสาธารณะ — ถ้าเว็บนี้ถูกเผยแพร่ขึ้นออนไลน์ คนอื่นที่รู้ URL ตรง ๆ (เช่น `.../admin.html`) จะเปิดดูได้เหมือนกัน (เพราะเว็บนี้ไม่มีระบบล็อกอิน) แต่ **แก้ไขเว็บจริงไม่ได้เอง** เพราะปุ่ม "อัปเดต content.js เลย" เขียนได้แค่ไฟล์ที่เปิด/เชื่อมไว้ **ในเครื่องของคนที่กดเท่านั้น** ไม่ได้เขียนขึ้นเซิร์ฟเวอร์หรือกระทบไฟล์ต้นทางของอาจารย์แต่อย่างใด

ถ้าอยากแก้เองตรง ๆ ในไฟล์ `content.js` (เช่น กรณีอยากพิมพ์เร็ว ๆ หรือ `admin.html`ใช้งานไม่ได้) ทำตามวิธีที่ 2 ด้านล่างได้เช่นกัน

## 0.5 แก้ข้อมูลจากเว็บจริงได้เลย (ไม่ต้องเปิดไฟล์ในเครื่อง) — สำหรับทีม

นอกจากเปิด `admin.html` ในเครื่องตัวเองแล้ว ตอนนี้เปิดหน้า admin **จากเว็บจริงบนอินเทอร์เน็ต** ได้ด้วย ที่ลิงก์:

```
https://netiyak-dev.github.io/SynergyClimate/admin.html
```

> หน้านี้**ไม่ได้ผูกลิงก์ไว้จากเมนูไหนของเว็บ** (ซ่อนไว้ ไม่มีใครเจอโดยบังเอิญ) แต่ใครก็ตามที่รู้ URL ตรง ๆ จะเปิด**ดู**หน้านี้ได้ เพราะรีโพเป็น public — แต่จะ**บันทึกข้อมูลจริงไม่ได้** ถ้าไม่มี GitHub Token ของตัวเองที่อาจารย์อนุญาตสิทธิ์เขียนไฟล์ให้ (ดูขั้นตอนด้านล่าง) ดังนั้นตัวที่ป้องกันจริง ๆ คือสิทธิ์ใน GitHub ไม่ใช่ตัว URL

### ขั้นตอนสำหรับอาจารย์ (เจ้าของรีโพ) — เชิญทีมเข้ามาแก้ไขได้

1. ไปที่ `https://github.com/netiyak-dev/SynergyClimate/settings/access`
2. กด **Add people** แล้วใส่ชื่อผู้ใช้ GitHub (username) หรืออีเมลของคนในทีมที่ต้องการให้แก้ไขได้
3. เลือกสิทธิ์ **Write** แล้วส่งคำเชิญ — คนนั้นต้องกด accept คำเชิญในอีเมล/GitHub ก่อนถึงจะใช้งานได้

### ขั้นตอนสำหรับแต่ละคนในทีม — สร้าง Token ของตัวเอง (ทำครั้งเดียว ใช้ได้จนกว่าจะหมดอายุ)

1. ไปที่ `https://github.com/settings/tokens?type=beta` (ต้อง login ด้วยบัญชี GitHub ของตัวเอง ที่ได้รับเชิญแล้ว)
2. กด **Generate new token**
3. ตั้งชื่อ เช่น `SynC-site admin` และเลือกวันหมดอายุ (แนะนำ 90 วัน — ปลอดภัยกว่าไม่หมดอายุเลย)
4. หัวข้อ **Repository access** เลือก **Only select repositories** แล้วเลือก `SynergyClimate`
5. หัวข้อ **Permissions → Repository permissions** หา **Contents** แล้วเปลี่ยนเป็น **Read and write**
6. กด **Generate token** ด้านล่างสุด แล้ว**คัดลอก token ที่ขึ้นมา** (รูปแบบ `github_pat_...`) — หน้านี้จะแสดง token ให้เห็นแค่ครั้งเดียว ปิดไปแล้วดูซ้ำไม่ได้ ต้องสร้างใหม่ถ้าทำหาย
7. เปิดหน้า admin บนเว็บจริง → กดปุ่ม **"🔑 ตั้งค่า GitHub Token"** มุมขวาบน → วาง token ที่คัดลอกมา → กด **บันทึก Token**

> 🔒 **ข้อควรระวังเรื่อง Token**
> - Token นี้เทียบเท่ารหัสผ่านเข้าถึงไฟล์ในรีโพ — **ห้ามส่งให้ใครทางแชท อีเมล หรือที่อื่นเด็ดขาด** รวมถึงห้ามส่งให้ Claude ด้วย
> - Token จะถูกเก็บไว้ในเบราว์เซอร์ของคนนั้นเองเท่านั้น (sessionStorage) และจะ**หายไปอัตโนมัติเมื่อปิดแท็บ/ปิดเบราว์เซอร์** ต้องวางใหม่ทุกครั้งที่เปิดหน้า admin รอบใหม่ — ถ้าใช้เครื่องสาธารณะ/เครื่องที่ใช้ร่วมกับคนอื่น ควรกด "ล้าง Token" ก่อนออกจากหน้าเสมอ
> - ถ้า token หมดอายุหรือหลุด ให้ไปสร้างใหม่ที่ `github.com/settings/tokens?type=beta` แล้วลบของเก่าทิ้งได้เลย (Revoke)

### วิธีใช้งานหน้า admin บนเว็บจริง

1. เข้า `https://netiyak-dev.github.io/SynergyClimate/admin.html`
2. แก้ข้อมูลในฟอร์มตามปกติ (เหมือนเปิดจากเครื่องตัวเอง)
3. กดปุ่ม **"☁️ บันทึกขึ้น GitHub"** มุมขวาบน — ระบบจะ commit ไฟล์ `content.js` ใหม่ขึ้นรีโพให้อัตโนมัติ
4. เว็บจริงจะอัปเดตให้เห็นภายใน ~1 นาที (GitHub Pages ใช้เวลาประมวลผลสักครู่)
5. ถ้ามีข้อความแจ้งเตือน "มีคนบันทึกทับไปก่อนหน้าแล้ว" แปลว่ามีคนอื่นในทีมเพิ่งบันทึกไปก่อน — ให้ **รีโหลดหน้าใหม่** แล้วแก้ไขซ้ำอีกครั้ง เพื่อไม่ให้ข้อมูลของเพื่อนร่วมทีมหาย

ปุ่ม **"💾 อัปเดต content.js ในเครื่องนี้"** (เดิมคือ "อัปเดต content.js เลย") ยังใช้ได้ตามปกติเมื่อเปิด `admin.html` จากในเครื่องตัวเอง (ไม่ใช่จากเว็บ) สำหรับใครที่อยากแก้ไฟล์ในเครื่องตัวเองไว้ดูก่อน แล้วค่อย commit/push เองทีหลังตามปกติ

## 1. ไฟล์ในโฟลเดอร์นี้มีอะไรบ้าง

| ไฟล์ | หน้าที่ | ต้องแก้ไหม |
|---|---|---|
| `admin.html` | **เครื่องมือฟอร์มสำหรับแก้เนื้อหา** (แนะนำให้ใช้อันนี้) | ✅ เปิดใช้ได้เลย ไม่ต้องแก้ไฟล์ |
| `assets/content.js` | **เนื้อหาทั้งหมด** (ข่าว โครงการ วิจัย ทีม บริจาค) | ✅ แก้ตรง ๆ ได้ หรือให้ `admin.html` สร้างให้ |
| `index.html` | โครงหน้าเว็บ | ❌ ไม่ต้องแก้ |
| `assets/styles.css` | หน้าตา/สี/ฟอนต์ | ❌ ไม่ต้องแก้ |
| `assets/app.js` | ตัวประกอบหน้าเว็บ | ❌ ไม่ต้องแก้ |

> 👉 สรุป: **แก้แค่ `content.js` ไฟล์เดียว** ที่เหลือปล่อยไว้

## 2. วิธีที่ 2: แก้ไฟล์ `content.js` ด้วยตนเอง (ไม่ผ่าน `admin.html`)

ส่วนนี้สำหรับใครที่อยากแก้โค้ดตรง ๆ เอง หรือกรณีเปิด `admin.html` ไม่ได้ — ถ้าใช้ `admin.html` อยู่แล้วข้ามไปข้อ 7 ได้เลย

### กฎทอง 3 ข้อ (ท่องไว้ก่อนแก้)

1. แก้เฉพาะข้อความ **ในเครื่องหมายคำพูด** `"..."` เท่านั้น
2. **ห้ามลบ** สัญลักษณ์ `"`  `,`  `{`  `}`  `[`  `]`
3. ถ้าในข้อความมีเครื่องหมาย `"` ให้เปลี่ยนเป็น `'` แทน (เช่น `'ข้อความ'`)

ตัวอย่างที่ถูก:
```js
title: "เปิดรับสมัครนักวิจัยร่วมโครงการ",
```
ตัวอย่างที่ **ผิด** (ลืมใส่ `,` ท้ายบรรทัด → เว็บจะพัง):
```js
title: "เปิดรับสมัครนักวิจัยร่วมโครงการ"
```

## 3. วิธีทำสิ่งที่ใช้บ่อย

### ➕ เพิ่มข่าวใหม่ 1 อัน
เปิด `content.js` หา `news: [` แล้ววางบล็อกนี้ต่อ **ไว้บนสุด** (ข่าวใหม่อยู่บน):
```js
{
  date:    "10 สิงหาคม 2568",
  tag:     "กิจกรรม",
  title:   "หัวข้อข่าวของคุณ",
  summary: "รายละเอียดสั้น ๆ 1–2 บรรทัด",
  image:   "",   // ลิงก์รูป (ดูข้อ 4) หรือเว้นว่าง
  link:    "",   // ลิงก์อ่านต่อ เช่นโพสต์ Facebook หรือเว้นว่าง
},
```

### ✏️ แก้ข่าว/โครงการเดิม
หาข้อความเดิม แล้วพิมพ์ทับในเครื่องหมายคำพูด

### 🗑️ ลบข่าว/โครงการ
ลบทั้งบล็อกตั้งแต่ `{` ถึง `},` (ระวังอย่าลบของอันอื่นติดไป)

### 👤 เพิ่มสมาชิกทีม
หา `team: [` แล้วเพิ่มบล็อก:
```js
{
  name:  "ชื่อ นามสกุล",
  role:  "ตำแหน่ง / Position",
  photo: "",   // ลิงก์รูปถ่าย (ถ้าไม่ใส่ จะขึ้นเป็นช่องลายใบไม้แทน)
  photoPosition: "",   // ปรับตำแหน่งโฟกัสรูป ถ้ารูปตัด "หน้า" ไม่พอดีกรอบ (ดูข้อ 4)
  link:  "",   // ลิงก์โปรไฟล์ (ถ้ามี)
},
```
รูปทีมงานจะแสดงเป็นภาพใหญ่เต็มกรอบด้านบนการ์ด (ครอบตัดแบบ cover) เหมือนการ์ด "งานของเรา"

### 📄 เพิ่มงานวิจัย/เอกสาร
หา `publications: [` แล้วเพิ่มบล็อก:
```js
{
  year:    "2025",
  title:   "ชื่อผลงาน",
  authors: "ชื่อผู้เขียน",
  venue:   "ประเภท เช่น Working Paper / Journal",
  link:    "",   // ลิงก์ไฟล์ PDF (ถ้ามี)
},
```

### 📅 เพิ่มกิจกรรมในปฏิทิน
หา `events: [` แล้วเพิ่มบล็อก:
```js
{ date: "2026-08-20", time: "09:00–16:00", title: "ชื่อกิจกรรม", location: "สถานที่", link: "" },
```
⚠️ **สำคัญเรื่องวันที่:** ใช้รูปแบบ `"ปีค.ศ.-เดือน-วัน"` เช่น `"2026-08-20"`
- ปี ค.ศ. **2026 = พ.ศ. 2569** (เอา พ.ศ. ลบ 543)
- เดือน/วัน เลข 1 หลักก็ได้ เช่น `"2026-9-5"`
- ระบบจะแสดงเป็น "สิงหาคม 2569" และวางลงช่องวันให้เองอัตโนมัติ
- วันที่มีกิจกรรมจะไฮไลต์ในปฏิทิน คลิกแล้วเลื่อนไปที่รายการด้านข้าง
- ถ้าไม่มีเวลา ให้เว้น `time: ""` ได้

### 🖼️ เพิ่มรูปในแกลเลอรีภาพกิจกรรม
หา `gallery: [` แล้วเพิ่มบล็อก:
```js
{ image: "ลิงก์รูป", caption: "คำบรรยายรูป" },
```
- `image` ใส่เป็น **ลิงก์รูป (URL)** — ดูวิธีได้ลิงก์รูปในข้อ 4
- รูปที่มีลิงก์จะ **คลิกขยายดูได้** (เลื่อนซ้าย-ขวา, กด Esc ปิด)
- ถ้าเว้น `image: ""` จะขึ้นเป็นช่องลายใบไม้ (ไว้เตรียมที่รอใส่รูป)

## 4. วิธีใส่รูปภาพ

ช่อง `image:` / `photo:` / `qrImage:` ต้องใส่เป็น **ลิงก์รูป (URL)** ไม่ใช่ไฟล์จากเครื่อง
วิธีได้ลิงก์รูป เลือกทางใดทางหนึ่ง:
- **(ง่ายที่สุด) กดปุ่ม "⬆ อัปโหลดรูป" ใน `admin.html`** — เลือกรูปจากเครื่อง ระบบย่อรูป (ด้านยาวไม่เกิน 1600px, JPEG)
  แล้วเก็บในโฟลเดอร์ Google Drive `SynergyClimate-web-images` และเติมลิงก์ให้อัตโนมัติ จากนั้นกดบันทึกเนื้อหาตามปกติ
  - ตั้งค่าครั้งเดียว: ติดตั้ง Apps Script ตามข้อ 6 (วางทั้ง `Code.gs` และ `Upload.gs`) → ใน Google Sheet กดเมนู
    **📧 ข่าวสาร → 4) ตั้งรหัสอัปโหลดรูป** → แจ้งรหัสให้ผู้ดูแลเว็บ *เป็นการส่วนตัว* (ห้ามใส่ในไฟล์ของเว็บหรือ GitHub)
  - ใช้ URL เดียวกับช่อง **Action URL** ในแท็บ "สมัครรับข่าวสาร" · ครั้งแรกของแต่ละรอบ ระบบจะถามรหัสอัปโหลด
  - รูปที่อัปโหลดเป็น **สาธารณะ** (ทุกคนที่มีลิงก์ดูได้) อย่าอัปโหลดรูปที่ไม่ต้องการเผยแพร่ · ลบรูปได้จากโฟลเดอร์ใน Drive
  - ถ้าขึ้นว่า *บัญชีไม่อนุญาตให้แชร์* แสดงว่าบัญชีองค์กรปิดการแชร์ออกภายนอก ให้ deploy สคริปต์ด้วยบัญชี Gmail กลางของกลุ่มแทน
  - ลิงก์รูปจาก Drive เป็นช่องทางที่ Google ไม่ได้รับประกันสำหรับการฝังบนเว็บ ถ้าวันหนึ่งรูปไม่ขึ้น ให้ย้ายรูปสำคัญ (เช่น โลโก้/QR) มาไว้ใน `assets/`
- อัปโหลดรูปเข้าคลังสื่อของ WordPress เดิม แล้วก็อปลิงก์รูปมาใส่
- หรือวางไฟล์รูปไว้ในโฟลเดอร์ `assets/` แล้วใส่เป็น `"assets/ชื่อรูป.jpg"`

ถ้าเว้นว่าง `""` ระบบจะใส่ภาพพื้นหลังลายใบไม้ให้อัตโนมัติ (ไม่พัง)

### 🖼️ ปรับรูปทีมงานให้ "หน้า" อยู่ในกรอบพอดี
การ์ดทีมงานจะครอบตัดรูปเต็มกรอบด้านบน (แบบเดียวกับการ์ด "งานของเรา") ถ้ารูปไหนถูกตัดจนหน้าโผล่ไม่พอดี
ให้เติมค่า `photoPosition:` ของคนนั้นใน `team:` เพื่อเลื่อนจุดโฟกัสของภาพ เช่น:
- `photoPosition: "center top"` — เลื่อนขึ้นให้เห็นส่วนบน/หัวเต็ม ๆ
- `photoPosition: "center 15%"` — เลื่อนขึ้นเล็กน้อย (ค่ายิ่งน้อย ยิ่งเลื่อนขึ้น)
- `photoPosition: "center bottom"` — เลื่อนลงให้เห็นส่วนล่างของภาพ

ถ้าเว้นว่าง `""` ระบบจะใช้ค่าเริ่มต้น (`center 22%`) ซึ่งเหมาะกับรูปโปรไฟล์ส่วนใหญ่อยู่แล้ว

## 6. การแจ้งเตือน & รับข่าวสาร

### 🗓️ ปุ่ม "เพิ่มลงปฏิทิน" (มีให้อัตโนมัติแล้ว)
ทุกกิจกรรมในปฏิทินจะมีปุ่ม **Google** และ **Apple / Outlook (.ics)** ให้ผู้เข้าชมกดเพิ่มกิจกรรมลงปฏิทินส่วนตัว
แล้วปฏิทินของเขาจะเตือนเอง — **ไม่ต้องตั้งค่าอะไรเพิ่ม** แค่ใส่กิจกรรมใน `events:` ให้ครบ (วันที่/เวลา/สถานที่)

### 📧 ฟอร์มสมัครรับข่าวสาร (ต้องเชื่อมต่อ Google 1 ครั้ง)
หน้าเว็บมีแถบ "สมัครรับข่าวสาร" อยู่แล้ว รายชื่อจะเก็บลง **Google Sheet** ผ่าน **Google Apps Script**
(โค้ดอยู่ที่ `apps-script/newsletter/Code.gs`) ระบบทำงานแบบ *ยืนยันสองขั้น (double opt-in)*:
ผู้สมัครกรอกอีเมล → ได้รับอีเมลยืนยัน → กดลิงก์แล้วจึงนับเป็นสมาชิก และทุกอีเมลมีลิงก์ยกเลิกรับข่าว

**ติดตั้งครั้งเดียว (ประมาณ 10 นาที):**

1. สร้าง Google Sheet ใหม่ (แนะนำใช้บัญชีกลางของกลุ่ม เพราะอีเมลจะถูกส่งในนามบัญชีนี้) ตั้งชื่อ เช่น `SynergyClimate Newsletter`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script** → ลบโค้ดเดิมทิ้ง → วางเนื้อหาทั้งหมดของ `Code.gs` → กด **+ → สคริปต์ (Script)** ตั้งชื่อ `Upload` แล้ววางเนื้อหาของ `Upload.gs` → กดบันทึก
3. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)** → ประเภท **เว็บแอป (Web app)**
   - *Execute as:* **Me (ฉัน)**
   - *Who has access:* **Anyone (ทุกคน)**
   - กด Deploy → อนุญาตสิทธิ์ตามที่ Google ถาม → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
4. เปิด `admin.html` → แท็บ **สมัครรับข่าวสาร** → วาง URL ในช่อง **Action URL** → บันทึก `content.js` ตามปกติ
5. กลับไปที่ Sheet กดรีเฟรช จะมีเมนู **📧 ข่าวสาร** → กด **1) ตั้งค่าแผ่นงาน** หนึ่งครั้ง
6. ทดสอบ: กรอกอีเมลตัวเองที่หน้าเว็บ → ควรได้อีเมลยืนยัน → กดลิงก์ → ในแผ่นงาน `Subscribers` สถานะเปลี่ยนเป็น `active`

**วิธีส่งข่าวถึงสมาชิก:** เปิด Sheet → แผ่นงาน `Compose` → พิมพ์หัวข้อ (B1) และเนื้อหา (B2) →
เมนู **📧 ข่าวสาร → 2) ส่งทดสอบถึงตัวเอง** ตรวจดูก่อน → **3) ส่งข่าวถึงสมาชิกทั้งหมด**
(ส่งเฉพาะคนที่สถานะ `active` · ถ้าโควตาไม่พอหรือส่งไม่ครบ กดส่งซ้ำได้ ระบบไม่ส่งซ้ำคนเดิม)

**ข้อควรรู้:**
- **โควตาอีเมลต่อวัน** ขึ้นกับประเภทบัญชี Google (บัญชีทั่วไปน้อยกว่าบัญชี Workspace มาก) และนับรวมอีเมลยืนยันด้วย — ดูตัวเลขปัจจุบันที่หน้า *Quotas for Google Services* ของ Google
- **แก้โค้ดแล้วต้อง Deploy ใหม่:** Deploy → *Manage deployments* → ✏️ → Version: **New version** (URL เดิมไม่เปลี่ยน) · ถ้ากด *New deployment* จะได้ URL ใหม่ และลิงก์ยืนยัน/ยกเลิกในอีเมลเก่าจะใช้ไม่ได้
- **PDPA:** Sheet นี้มีข้อมูลส่วนบุคคล แชร์เฉพาะผู้ดูแลที่จำเป็น ห้ามตั้งเป็น "ทุกคนที่มีลิงก์" · อย่าแก้/ลบคอลัมน์ `token` และ `status` ด้วยมือ (ยกเว้นลบทั้งแถวเมื่อเจ้าของข้อมูลขอให้ลบ)
- ยังใช้บริการอื่น (MailerLite/Brevo) ได้เหมือนเดิม: ใส่ `action` URL ของบริการนั้นแทน และตั้ง `emailField` (MailerLite = `fields[email]` · Brevo/Mailchimp = `EMAIL`)

> 💡 อยากให้ **คนในทีม** ได้รับเตือนกิจกรรมอัตโนมัติ: สร้าง **Google Calendar ปฏิทินเดียวแชร์กันในทีม** แล้วให้ทุกคน subscribe ครั้งเดียว — Google จะเตือนให้เอง (แยกจากฟอร์มสมัครด้านบน)

## 7. เผยแพร่ขึ้นเว็บจริง + พ่วงลิงก์จากหน้าแรก

หน้านี้เป็นไฟล์ static ธรรมดา วางที่ไหนก็ได้ เลือกวิธีที่เหมาะกับทีม:

**ทางเลือก A — วางบนโดเมน mahidol (น่าเชื่อถือสูงสุด)**
1. ส่งทั้งโฟลเดอร์นี้ให้ทีม IT อัปโหลดไปไว้ใต้เว็บเดิม เช่น `synergyclimate.mahidol.ac.th/hub/`
2. ขอให้ IT เพิ่มเมนู (เช่น "งานของเรา" หรือ "ข่าวสาร") ให้ชี้มาที่ URL นั้น — **ทำครั้งเดียว**
3. เวลาจะอัปเดต: แก้ `content.js` แล้วส่งไฟล์เดียวนั้นให้ IT อัปโหลดทับ

**ทางเลือก B — อัปเดตเองได้ 100% ไม่ต้องพึ่ง IT (GitHub Pages / Netlify ฟรี)**
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub แล้วเปิด GitHub Pages (จะได้ URL ฟรี)
2. ขอให้ IT เพิ่มลิงก์เมนูจากหน้าแรกชี้มาที่ URL นั้น — ครั้งเดียว
3. เวลาจะอัปเดต: แก้ไฟล์ `content.js` ผ่านหน้าเว็บ GitHub ได้เลย เว็บจะอัปเดตอัตโนมัติภายในไม่กี่นาที

**ทางเลือก C — ฝังในหน้า WordPress (iframe)**
ให้ IT สร้างหน้าเปล่าใน WordPress แล้วฝัง (embed) URL ของหน้านี้เข้าไป

> แนะนำ: ถ้าต้องการอัปเดตเองบ่อย ๆ โดยไม่รบกวน IT ให้ใช้ **ทางเลือก B**
> ถ้าเน้นให้ URL อยู่ใต้ mahidol.ac.th ให้ใช้ **ทางเลือก A**
