# คู่มือ: พื้นที่เฉพาะสมาชิก (ติดตามแผนงาน & KPI)

เป้าหมาย: มีหน้า "เฉพาะสมาชิก" ที่ **ล็อกอินจริง** สำหรับติดตามแผนงาน/ตัวชี้วัด
โดยหน้าเว็บสาธารณะแค่มีปุ่ม 🔒 "สำหรับสมาชิก" ลิงก์ไปยังพื้นที่นั้น

---

## ทำไมต้องทำแบบนี้ (อ่านสั้น ๆ)

หน้าเว็บของเราเป็น **static** — **ล็อกอินเองอย่างปลอดภัยไม่ได้** เพราะถ้าซ่อนข้อมูล/รหัสไว้ในหน้าเว็บ
คนเปิดดู source code ก็เห็นหมด ดังนั้นเราให้ **Google** เป็นคนคุมการล็อกอินแทน (ปลอดภัย + อัปเดตง่าย + ไม่ต้องรอ IT)

---

## ขั้นตอน (ทำครั้งเดียว ~15 นาที)

### 1) เอาไฟล์ติดตามงานขึ้น Google
- อัปโหลด `KPI-workplan-template.xlsx` ขึ้น Google Drive
- คลิกขวาที่ไฟล์ › **เปิดด้วย › Google ชีต** (จะได้ไฟล์ Google ชีตที่แก้ออนไลน์ได้)
- ไฟล์มี 4 แท็บ: **คำแนะนำ / แผนงาน / ตัวชี้วัด / สรุปภาพรวม** (สรุปภาพรวมคำนวณให้อัตโนมัติ)

### 2) กรอกข้อมูล
- **แผนงาน**: งาน/กิจกรรม, ผู้รับผิดชอบ, วันเริ่ม–วันครบกำหนด, สถานะ (เลือกจากรายการ), ความคืบหน้า %
- **ตัวชี้วัด**: ชื่อ KPI, หน่วย, เป้าหมาย, ผลปัจจุบัน → ช่อง "% บรรลุเป้า" และ "สถานะ" คิดให้เอง
- ลบแถวที่มีคำว่า **(ตัวอย่าง)** ออกได้เมื่อเริ่มกรอกจริง

### 3) ตั้งค่าแชร์ "เฉพาะสมาชิก" (สำคัญที่สุด)
กดปุ่ม **แชร์ (Share)** มุมขวาบนของ Google ชีต แล้วเลือกวิธีใดวิธีหนึ่ง:

- **แนะนำ — แชร์เจาะจงรายคน:** พิมพ์อีเมลสมาชิกทีละคน ตั้งสิทธิ์เป็น **ผู้อ่าน (Viewer)** หรือ **ผู้แสดงความคิดเห็น (Commenter)** (ให้สิทธิ์ **ผู้แก้ไข** เฉพาะคนที่ต้องกรอกข้อมูล)
- **หรือ — ทั้งโดเมนมหิดล:** ตั้ง "ผู้ใช้ทุกคนใน **Mahidol University** ที่มีลิงก์" → เฉพาะคนที่ล็อกอิน `@mahidol.ac.th` เท่านั้นที่เข้าได้

> ⛔ **อย่าตั้งเป็น "ทุกคนที่มีลิงก์ / สาธารณะ"** เพราะจะไม่เป็นความลับอีกต่อไป

### 4) เอาลิงก์มาใส่ปุ่ม "สำหรับสมาชิก" บนเว็บ
- ในหน้าแชร์ กด **คัดลอกลิงก์ (Copy link)**
- เปิด `assets/content.js` หา `memberArea:` แล้ววางลิงก์ที่ช่อง `url`:
```js
memberArea: {
  enabled: true,
  label:   "สำหรับสมาชิก",
  url:     "วางลิงก์ Google ชีต/แดชบอร์ด ที่นี่",
},
```
- เผยแพร่เว็บ → ปุ่ม 🔒 "สำหรับสมาชิก" (มุมขวาบน) จะพาไปยังไฟล์ที่ **ต้องล็อกอิน Google** ก่อนถึงจะเห็น
- คนนอกที่ไม่มีสิทธิ์กดเข้าไป จะเจอหน้า "ขอสิทธิ์เข้าถึง" ของ Google (เข้าไม่ได้) — ปลอดภัย

## (ทางเลือก) ทำแดชบอร์ดสวย ๆ ด้วย Looker Studio

ถ้าอยากได้กราฟ/มิเตอร์สรุป KPI แบบแดชบอร์ด:
1. ไปที่ **lookerstudio.google.com** › สร้างรายงานใหม่ › เลือกแหล่งข้อมูล **Google ชีต** › เลือกไฟล์นี้
2. ลากสร้างกราฟ (เช่น จำนวนงานตามสถานะ, %บรรลุ KPI)
3. กด **แชร์** ของ Looker Studio แบบเดียวกับข้อ 3 (เจาะจงอีเมล/โดเมน)
4. เอาลิงก์รายงานมาใส่ `memberArea.url` แทน (จะได้หน้าตาเป็นแดชบอร์ดแทนตารางดิบ)

## การดูแลสิทธิ์

- มีคนเข้าทีมใหม่ → เพิ่มอีเมลในหน้าแชร์
- มีคนออกจากทีม → **ลบอีเมลออกจากหน้าแชร์** (ตัดสิทธิ์ทันที)
- ตรวจรายชื่อผู้มีสิทธิ์เป็นระยะ ๆ

---

## ถ้าต้องการมากกว่านี้ (พึ่ง IT)

- อยากได้ URL สั้นใต้ `synergyclimate.mahidol.ac.th/...` หรือควบคุมสิทธิ์แบบองค์กรเข้มขึ้น
  → ให้ IT ทำ **หน้าเฉพาะสมาชิกใน WordPress** หรือวางเว็บไว้หลัง **Cloudflare Access** (ล็อกอิน SSO ระดับโดเมน)
- แนวทาง Google ด้านบนพอเพียงสำหรับการติดตามแผนงาน/KPI ภายในทีมส่วนใหญ่ และเริ่มใช้ได้เองทันที
