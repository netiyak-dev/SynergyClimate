SynergyClimate — เครื่องมือจัดการเนื้อหา

แก้ข้อมูลด้วยฟอร์ม แล้วส่งออกเป็นไฟล์ assets/content.js — ไม่ต้องแตะโค้ดเอง
ยังไม่มีการแก้ไข เบราว์เซอร์นี้บันทึกไฟล์ตรงไม่ได้ — ใช้ปุ่มดาวน์โหลดแทน

เชื่อมต่อ GitHub เพื่อบันทึกขึ้นเว็บจริง

ต้องมี GitHub Personal Access Token ของบัญชีตัวเองที่ได้รับสิทธิ์เขียนไฟล์ในรีโพ SynergyClimate ก่อน (ขอให้อาจารย์เนติยาเชิญเป็น collaborator ในรีโพก่อน ถ้ายังไม่ได้รับเชิญ) วิธีสร้าง Token ดูได้ในไฟล์ README-วิธีอัปเดต.md หัวข้อ "เชื่อมต่อ GitHub"

Token นี้เก็บไว้ในเบราว์เซอร์นี้เท่านั้น (หายไปเมื่อปิดแท็บ) และส่งตรงไปที่ GitHub เท่านั้น ไม่ผ่านเซิร์ฟเวอร์อื่นใด — ห้ามส่ง Token นี้ให้ใครทางแชทหรือที่อื่นเด็ดขาด

โค้ด content.js ที่สร้างจากข้อมูลปัจจุบัน

คัดลอกข้อความทั้งหมดด้านล่าง แล้ววางทับไฟล์ assets/content.js เดิม หรือกดปุ่ม "ดาวน์โหลด" เพื่อได้ไฟล์พร้อมใช้ทันที — หรือถ้าเชื่อมไฟล์ไว้แล้ว ใช้ปุ่ม "💾 อัปเดต content.js เลย" ที่แถบด้านบนแทนได้เลย ไม่ต้องคัดลอก-วางเอง
